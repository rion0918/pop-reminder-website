# デザイン実装ガイド

## 世界観

「忘れる前に、ふわっと。」をメインコピーに、頭に浮かんだ予定を気軽に残して、覚え続ける負担を手放せることを伝えます。白い余白、大きな日本語の見出し、鮮やかなブルーを軸に、アプリのやさしさと広告としての視認性を両立します。

## ページ構成

1. ヒーロー：コピー、既存のアプリ画面、リリースを待つ導線。
2. 共感：買い物や返却など、日常の小さな予定を手放す価値。
3. 機能：泡の表示、前日・当日の通知、Androidウィジェット。
4. 使い方：入力、日付・時間の選択、保存の3ステップ。
5. 安心設計とFAQ：アカウント不要、端末内保存、公開予定の説明。
6. 待機リスト：匿名参加と取り消し。個別のメール通知は行わず、公開情報は開発者のXへ案内。

## 泡UI

アプリの予定表示を、既存の `.app-bubble` 構造で表現します。予定の表示例は角丸カードではなく泡を使い、通知の表示例のみ通知カードとして扱います。

- 今日：赤系。
- 明日：オレンジ系。
- 3日以内：黄色系。
- 先の予定：水色系。

白いリング、内側の色、光の反射を保ち、本文の読みやすさを優先します。装飾用の泡は支援技術から隠し、クリックできるように見せません。

## レスポンシブと動き

- PCはコピーとアプリ画面を左右に配置し、スマートフォンは縦に配置。
- 機能カードは画面幅に合わせて2列から1列へ変更。
- FAQは標準の `details` / `summary` を使用。
- 泡の漂いとポインターに応じた端末の傾きは控えめに。
- `prefers-reduced-motion` でアニメーションを停止。
- JavaScriptが無効でも主要コンテンツを表示し、待機リストには案内を表示。
- フォーカス表示、本文へのスキップリンク、フォームの状況通知を維持。
