# デザイン実装ガイド

## 世界観

「ふわっと。」では、リマインダーをカードではなくシャボン玉として扱います。予定を覚え続ける負担から手放せる軽さと、必要な時までやさしく残る安心感を、透明な膜・光・わずかな漂いで表現します。

## 正本

泡UIの仕様はアプリ本体の次の実装を正本とします。

- `src/features/reminders/components/ReminderBubble.tsx`: 膜、リング、反射、文字、誕生・待機・押下表現
- `src/features/reminders/components/reminderBubbleIdleMotion.ts`: 待機モーション
- `src/features/reminders/components/reminderBubblePressMotion.ts`: 押下スプリング
- `src/features/reminders/utils/reminderDueColor.ts`: 期限から色を決める規則
- `src/constants/colors.ts`: 期限色と透明度

広告サイトでは、これらを`index.html`の`.app-bubble`構造と`styles.css`の共通スタイルへ翻訳しています。リマインダーの表示例を角丸カードへ戻さないでください。

## 期限色

| 期限 | 表現 |
| --- | --- |
| 今日 | 赤い膜と赤紫の文字 |
| 明日 | オレンジの膜と茶系の文字 |
| 3日以内 | 黄色い膜と黄土系の文字 |
| それより先 | 水色の膜と青い文字 |

泡は色面を不透明に塗りつぶさず、白い外周リング、内側の色リム、左上の大きな反射と小さな反射、中央の淡い色霧を重ねます。

## モーション

- 誕生: 下から8px、0.98倍で現れ、1.01倍を経て等倍へ落ち着く。
- 待機: 約4.6〜7.2秒かけてX方向0〜2.4px、Y方向2.2〜4.4px、回転0.35〜0.7度の範囲で漂う。
- ポインター: ヒーロー内では端末と泡が異なる奥行きで追従し、現在値から高減衰スプリングで目標へ移動する。
- 押下可能な要素: pointer-downで即座に反応し、0.97倍を基準にする。装飾だけの泡を偽のボタンにしない。

大きなパララックスや強いバウンドは使いません。動きは操作の因果関係と奥行きを伝えるために使います。

## アクセシビリティ

- `prefers-reduced-motion: reduce`では、漂いとパララックスを停止して泡を静止表示する。
- 情報をモーションだけで伝えない。
- 装飾用の泡は支援技術から隠し、操作できるように見せない。
- 文字は泡の色ではなく十分な濃度の期限別アクセント色を使う。
